### 🚀 Features

- ⚠️  **code:** require projectName instead of falling back to a base project ([7894969](https://github.com/dcat23/next-feature/commit/7894969))
- ⚠️  **feature:** apply server-only boundaries to client and logging features ([66aa971](https://github.com/dcat23/next-feature/commit/66aa971))
- **feature:** externalize and declare published library dependencies ([aa6b96d](https://github.com/dcat23/next-feature/commit/aa6b96d))
- ⚠️  **feature:** remove the base feature type ([77088b1](https://github.com/dcat23/next-feature/commit/77088b1))

### 🩹 Fixes

- **client:** detect axios and zod errors by shape; key zod errors by full path ([6d9525d](https://github.com/dcat23/next-feature/commit/6d9525d))
- **component:** import ApiResponse from clientPackage in form components ([88320eb](https://github.com/dcat23/next-feature/commit/88320eb))

### ⚠️  Breaking Changes

- **feature:** remove the base feature type  ([77088b1](https://github.com/dcat23/next-feature/commit/77088b1))
  --type=base is rejected; use --type=generic (the default).
  nx g next-feature:feature no longer defaults --name to "base".
- **code:** require projectName instead of falling back to a base project  ([7894969](https://github.com/dcat23/next-feature/commit/7894969))
  code generators no longer default projectName to 'base'.
  Pass --projectName (-p) or set
  generators["next-feature"].<generator>.projectName in nx.json.
- **client:** return a serializable ProblemDetail from withApi  ([6285894](https://github.com/dcat23/next-feature/commit/6285894))
  ApiResponse.error is now a ProblemDetail, not an ApiError.
  Use ApiError.of(response.error) for status helpers.
- **feature:** apply server-only boundaries to client and logging features  ([66aa971](https://github.com/dcat23/next-feature/commit/66aa971))
  ApiClient is no longer exported from @next-feature/client.
  Import it from @next-feature/client/server (lib/config/client.ts generated by
  earlier versions must update this import). Importing @next-feature/client/server
  or @next-feature/logging/server from a client component now fails the build.

### ❤️ Thank You
